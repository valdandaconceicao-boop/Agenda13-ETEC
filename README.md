# Projeto de Agenda — ETEC

Projeto acadêmico de Desenvolvimento de Sistemas voltado à criação de uma aplicação de agenda e ao exercício de organização de dados, telas e fluxos de usuário.

## Objetivo

Praticar a estruturação de uma aplicação com cadastro e consulta de informações, pensando em um fluxo simples para inclusão, visualização e manutenção de registros.

## Escopo previsto

- Organização de registros de agenda.
- Cadastro e consulta de informações.
- Estruturação de telas e fluxo de navegação.
- Prática de separação entre interface, regras e dados.
